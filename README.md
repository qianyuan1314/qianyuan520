# qianyuan520

## ReSukiSU Kernel Build

CI pipeline for onyx device

**How to use:**

1. Go to **Actions** tab
2. Click **Build onyx ReSukiSU Kernel**
3. Click **Run workflow**
4. Select inputs and run

**Features:**
- KernelSU/SusiSU root
- KPM/kpatch support
- SUSFS root hiding
- AK3 flashable package
